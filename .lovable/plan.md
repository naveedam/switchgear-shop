
# SwitchgearShop Marketplace - Production Readiness & GST Compliance Plan

## Executive Summary

The marketplace has a solid foundation but requires significant work for production readiness, particularly around GST compliance. This plan covers fixing critical issues, implementing GST-compliant invoicing, and adding seller/platform GST filing support.

---

## Phase 1: Critical Fixes for Production (Priority: High)

### 1.1 Security Fixes
- Review and fix RLS policies with `USING (true)` conditions
- Reduce OTP expiry to recommended threshold
- Enable leaked password protection
- Apply Postgres security patches via Supabase dashboard

### 1.2 Connect Real Data (Replace Mock Data)
- **Buyer OrdersPage**: Fetch orders from Supabase where `buyer_id = user.id`
- **SellerOrders**: Query orders containing products from the seller
- **SellerDashboard**: Calculate real stats from orders and products tables

### 1.3 Missing Core Features
- Profile editing functionality
- Email notifications for order status changes (edge function)
- Order tracking updates

## Phase 2: GST-Compliant Invoice System

### 2.1 Database Schema Updates

Add new columns to `invoices` table:
```text
seller_id           UUID        -- Reference to seller company
seller_gstin        TEXT        -- Seller's GSTIN
seller_name         TEXT        -- Seller's legal name
seller_address      JSONB       -- Full address with state code
buyer_gstin         TEXT        -- Buyer's GSTIN (nullable for B2C)
buyer_name          TEXT        -- Buyer's legal name
buyer_address       JSONB       -- Full address with state code
place_of_supply     TEXT        -- State code (e.g., "29" for Karnataka)
invoice_type        TEXT        -- 'B2B', 'B2C', 'EXPORT', 'SEZ'
cgst_rate           DECIMAL     -- CGST percentage
cgst_amount         DECIMAL     -- CGST amount
sgst_rate           DECIMAL     -- SGST percentage
sgst_amount         DECIMAL     -- SGST amount
igst_rate           DECIMAL     -- IGST percentage (for inter-state)
igst_amount         DECIMAL     -- IGST amount
reverse_charge      BOOLEAN     -- Is reverse charge applicable
irn                 TEXT        -- E-invoice IRN (nullable)
irn_date            TIMESTAMP   -- IRN generation date
qr_code_data        TEXT        -- QR code for e-invoice
e_way_bill_no       TEXT        -- E-way bill number
e_way_bill_date     TIMESTAMP   -- E-way bill date
financial_year      TEXT        -- e.g., "2025-26"
```

Create new `invoice_items` table:
```text
id                  UUID        PRIMARY KEY
invoice_id          UUID        -- FK to invoices
product_id          UUID        -- FK to products
description         TEXT        -- Item description
hsn_code            TEXT        -- HSN/SAC code
quantity            DECIMAL
unit                TEXT        -- e.g., "NOS", "KG"
unit_price          DECIMAL
discount            DECIMAL
taxable_value       DECIMAL
cgst_rate           DECIMAL
cgst_amount         DECIMAL
sgst_rate           DECIMAL
sgst_amount         DECIMAL
igst_rate           DECIMAL
igst_amount         DECIMAL
total               DECIMAL
```

Add GST fields to `companies` table:
```text
gstin               TEXT        -- GST registration number
pan_number          TEXT        -- PAN
legal_name          TEXT        -- Legal business name
trade_name          TEXT        -- Trade name
state_code          TEXT        -- Two-digit state code
gst_registration_type TEXT      -- 'Regular', 'Composition', 'Unregistered'
```

### 2.2 Invoice Number Generation

Create database function for sequential invoice numbering:
- Format: `SELLER-PREFIX/FY/SEQUENCE` (e.g., "ETS/25-26/00001")
- Unique per seller per financial year
- Auto-increment sequence

### 2.3 GST Calculation Logic

Create edge function `calculate-gst`:
- Input: seller state, buyer state, items with HSN codes
- Logic:
  - If same state: CGST + SGST (split 50-50)
  - If different states: IGST (full rate)
  - Look up tax rates from HSN codes
- Returns: Itemized tax breakdown

### 2.4 Invoice PDF Generation

Create edge function `generate-invoice-pdf`:
- Uses a PDF library (e.g., pdfmake or jsPDF)
- GST-compliant format with all required fields
- Company logo and signature
- QR code for e-invoice (when applicable)
- Store PDF in Supabase storage
- Return download URL

## Phase 3: Seller Invoice Management

### 3.1 Seller Invoice Dashboard

New page: `/seller/invoices`
- List all invoices generated by seller
- Filter by status, date range, buyer
- Search by invoice number
- Quick actions: View, Download PDF, Send to buyer

### 3.2 Generate Invoice from Order

- Allow editing buyer GSTIN (for B2B)

### 3.3 Manual Invoice Creation

- For sales outside the platform
- Required for complete GST return filing
- Same GST-compliant format

## Phase 4: GST Return Support

### 4.1 GSTR-1 Data Export (Seller Feature)

Monthly/quarterly export for sellers:

**B2B Invoices (Table 4A, 4B)**
- Recipient GSTIN
- Invoice number and date
- Invoice value
- Place of supply
- Taxable value, IGST, CGST, SGST

**B2C Large (Table 5A)** - Inter-state > ₹2.5 lakh
- Place of supply
- Taxable value, IGST

**B2C Small (Table 7)**
- Consolidated by state
- Taxable value, CGST, SGST

**HSN Summary (Table 12)**
- HSN code
- Description
- UQC (Unit)
- Total quantity
- Taxable value
- IGST, CGST, SGST, Cess

Export formats: JSON (GST portal compatible), Excel

### 4.2 GSTR-3B Summary (Seller Feature)

Monthly summary view:
- Outward taxable supplies
- Outward exempt/nil rated
- Inward supplies (reverse charge)
- Tax payable (IGST, CGST, SGST)

### 4.3 Platform GST Dashboard (Admin Feature)

For platform's own GST filing:
- Commission income summary
- Platform fee income
- TCS (Tax Collected at Source) if applicable
- Monthly/quarterly reports

## Phase 5: E-Invoice Integration (Optional, for >₹5Cr turnover)

### 5.1 NIC E-Invoice API Integration

Edge function `generate-e-invoice`:
- Connect to NIC (National Informatics Centre) API
- Generate IRN (Invoice Reference Number)
- Get signed QR code
- Store IRN and QR in invoice record

### 5.2 E-Way Bill Integration

For shipments >₹50,000:
- Generate e-way bill via NIC API
- Store e-way bill number
- Track validity
